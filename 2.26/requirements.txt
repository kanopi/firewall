# Documentation site toolchain.
#
# Install:   pip install -r docs/requirements.txt
# Preview:   mkdocs serve
# Build:     mkdocs build --strict
#
# Versions are pinned so a docs PR never fails because an upstream release
# changed rendering out from under it. Bump them deliberately.
#
# pymdown-extensions is held below 11 on purpose: mkdocs-material declares
# `pymdown-extensions~=10.2`, and 11.x installs over that without complaint
# only to fail at render time.
#
# mkdocs-redirects keeps every pre-2.25.0 URL working after the Diataxis
# restructure moved fourteen pages. The published release notes and the README
# link into the old paths and cannot be edited after the fact.
#
# mike publishes each release into its own subdirectory of gh-pages and
# maintains the version selector. It supersedes the direct ghp-import call the
# deploy job used to make -- see .circleci/config.yml for why that changed.
#
# ghp-import arrives as an mkdocs dependency and as a mike dependency. Pinned
# here because the deploy job's behaviour depends on it either way.
